# 생태 탐험대 구현 설계

대상은 초등학교 6학년이다. 사용자가 지정한 20개와 추가 50개, 총 70개의 생태계 구성요소를 두 단계로 분류한다. HTML/CSS/JavaScript 정적 파일로 구성해 파일을 직접 열거나 GitHub Pages에 게시할 수 있게 한다. 프레임워크와 서버 방식도 가능하지만 이 학습 활동에는 설치 없는 정적 파일이 적합하다.

- 혼자 학습: 70개 무작위 순서, 오답 시 같은 문제에서 재선택, 이전 문제로 이동, 정답 후 해설과 다음 버튼, 완료 화면.
- 게임: 실제 경과시간 기준 120초, 최종 정답 10점, 오답 0점과 자동 이동, 생물의 첫 단계 정답에는 점수를 주지 않음. 정답도 자동 이동. 70개를 모두 풀면 새로 섞어 계속 진행한다.
- 생물요소는 생산자 20개, 소비자 30개, 분해자 10개. 비생물요소 10개. 세균·균류의 다양성과 흙의 의미를 설명한다. 지렁이는 낙엽 등을 먹는 소비자로 분류한다.
- 정답과 설명은 data.js, 상태와 채점은 engine.js, 화면과 타이머는 app.js, 디자인은 styles.css가 담당한다.
- 모든 화면은 한국어, 키보드 조작 지원, 반응형. 개인정보나 외부 서비스를 사용하지 않는다.

## 구현 순서 및 검증

1. 먼저 Node 기본 테스트로 재선택·이전 이동·중복 채점 방지·시간 만료·70개 포함·순환 출제의 기대 동작을 작성하고 실패를 확인한다.
2. 데이터와 상태 로직을 구현하고 같은 테스트를 통과시킨다.
3. 홈·학습·게임·결과 화면을 연결하고 실제 브라우저로 동작과 좁은 화면을 확인한다.
4. README에 실행법, 파일별 역할, 추가 50개, 분류 기준과 GitHub Pages 게시법을 기록하고 ZIP으로 제공한다.
