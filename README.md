# 🌿 생태 탐험대

초등학교 6학년을 위한 **생태계 구성요소 분류 학습 프로그램**입니다. 생물요소와 비생물요소를 구별하고, 생물요소를 생산자·소비자·분해자로 나눕니다. 한국어로 제공하며 컴퓨터·태블릿·휴대폰 화면에 대응합니다.

## 1. 내 컴퓨터에서 실행하기

1. ZIP 파일을 내려받아 **먼저 압축을 풉니다**.
2. `index.html`을 Chrome, Edge, Safari 등 최신 브라우저로 엽니다.
3. **혼자 학습하기** 또는 **게임하기**를 선택합니다.

설치, 로그인, API 키, 인터넷 연결 없이 실행할 수 있습니다. 실제 실행에는 `index.html`, `styles.css`, `data.js`, `engine.js`, `app.js`, `favicon.svg`를 같은 폴더에 둡니다. ZIP 안의 HTML만 따로 꺼내지 마세요. 학습 진행과 점수는 현재 화면에서만 유지되며 새로고침하면 초기화됩니다.

## 2. GitHub에 올리고 웹 주소 만들기

1. GitHub에 로그인한 뒤 **New repository**를 선택합니다.
2. 저장소 이름을 `ecosystem-explorer` 등으로 정하고, 무료 개인 계정에서는 **Public** 저장소로 만듭니다.
3. 저장소의 **Add file → Upload files**에서 압축을 푼 파일을 업로드합니다. **`index.html`이 저장소 첫 화면에 보이는 최상위 위치**에 있어야 합니다. ZIP 자체를 올리거나 폴더 한 겹 안에 넣지 마세요.
4. **Commit changes**를 눌러 저장합니다.
5. **Settings → Pages → Build and deployment**로 이동합니다.
6. Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 선택하고 **Save**를 누릅니다. 기본 브랜치 이름이 다르면 실제 업로드한 브랜치를 고릅니다.
7. 배포가 끝나면 Pages에 표시된 주소를 열어 확인합니다. 보통 `https://사용자이름.github.io/ecosystem-explorer/` 형태입니다.

수정한 파일을 같은 위치에 다시 업로드하고 커밋하면 웹사이트도 갱신됩니다. 배포 오류는 저장소의 **Actions** 탭에서 확인할 수 있습니다.

공식 안내: [GitHub Pages 게시 소스 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), [GitHub Pages 사이트 만들기](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## 3. 학습·게임 규칙

| 기능 | 혼자 학습하기 | 게임하기 |
|---|---|---|
| 출제 | 70개를 무작위로 한 번씩 | 무작위 출제, 70개를 다 풀면 다시 섞음 |
| 분류 단계 | 생물/비생물 → 생물이면 역할 선택 | 동일 |
| 제한 시간 | 없음 | 2분(120초) |
| 오답 | **다시 선택해 보세요.** 표시, 같은 단계 재도전 | 0점, 정답을 잠깐 보여준 뒤 자동 이동 |
| 정답 | 해설 확인 후 **다음 문제** 선택 | 최종 정답마다 **10점**, 자동 이동 |
| 이전 문제 | **이전 문제로 돌아가기**, 이미 맞힌 상태 유지 | 제공하지 않음 |
| 완료 | 70개 학습 완료 화면 | 점수, 푼 문제 수, 정답률, 틀린 구성요소 복습 |

생물요소라는 첫 번째 선택만 맞힌 경우에는 점수가 없습니다. 생산자·소비자·분해자까지 맞혀야 10점입니다. 비생물요소는 한 단계만 맞히면 10점입니다. 자동 이동 대기시간은 0.85초이며 이때도 제한시간이 흐릅니다. 시간이 정확히 끝나면 추가 답안을 채점하지 않습니다. 화면을 다른 탭으로 바꿔도 시간이 흐르며 다시 돌아오면 실제 경과시간을 반영합니다.

키보드의 `Tab`으로 버튼을 옮기고 `Enter` 또는 `Space`로 선택할 수 있습니다. 홈 화면의 **70가지 구성요소 도감**에서는 분류별 목록과 이름 검색을 제공합니다.

## 5. 수업에서 설명할 분류 기준

- 생산자·소비자·분해자는 모두 **생물요소**입니다. 비생물요소에는 물질뿐 아니라 온도·습도 같은 조건도 포함됩니다.
- **세균·곰팡이·버섯**은 이 활동에서 죽은 생물이나 배설물을 분해하는 예를 뜻합니다. 모든 세균이나 모든 버섯이 같은 방식으로 양분을 얻는 것은 아닙니다. 예를 들어 광합성하는 세균과 다른 생물과 공생하는 균류도 있습니다.
- **흙**은 흙 자체를 분류합니다. 그 안에 사는 세균·곰팡이·동물까지 비생물이라는 뜻은 아닙니다.
- **지렁이**는 낙엽 등의 유기물을 먹는 소비자(부식성 동물)로 다룹니다. 분해를 돕는 넓은 의미의 분해자로 설명하는 자료도 있지만, 이 프로그램에서는 유기물을 외부에서 분해하고 흡수하는 세균·균류와 구별합니다. 수업에서 사용하는 교과서의 분류 기준도 함께 확인해 주세요.
- 개구리·나비는 다 자란 개체, 무당벌레는 진딧물을 먹는 예, 달팽이는 식물을 먹는 예를 기준으로 합니다. 이모지는 관심을 돕는 **상징 그림**으로, 실제 종의 모습을 판별하는 자료가 아닙니다.
- 70개는 여러 환경의 예를 모은 목록입니다. 호랑이·미역·토끼풀이 모두 한 장소에서 사는 하나의 생태계를 뜻하지 않습니다.

개념 참고: [미국 국립공원청 생태계 수업 자료](https://www.nps.gov/common/uploads/teachers/lessonplans/Ecosystems%20Lesson%20Plan_5082.pdf), [Khan Academy의 생산자·소비자·분해자 설명](https://www.khanacademy.org/science/biology/ecology/energy-flow-through-ecosystems/a/producers-and-consumers).

## 6. 어떻게 만들었나요? 파일별 역할

```text
index.html          웹페이지의 기본 구조와 한국어 설정
styles.css          초록색 탐험 노트 디자인과 반응형 화면
data.js             70개 항목의 이름·분류·그림·해설
engine.js           문제 순서, 분류 단계, 채점, 이전/다음, 120초 제한
app.js              화면 표시, 클릭 처리, 실제 타이머, 결과/복습 화면
favicon.svg         브라우저 탭 아이콘
.nojekyll           GitHub Pages에서 정적 파일을 그대로 게시
tests/engine.test.cjs  핵심 동작 자동 테스트
package.json        개발자용 테스트 실행 명령
docs/implementation.md 구현 설계
```

만드는 순서는 **문제 데이터 작성 → 분류/채점 로직 작성 → 화면 연결 → 디자인 → 테스트 → GitHub Pages 게시**입니다.

1. `data.js`에서 각 항목에 `name`, `emoji`, `kind`, `role`, `explanation`을 기록합니다.
2. `engine.js`의 `Session`이 `kind` 단계에서 생물 여부를 확인하고, 생물이면 `role` 단계로 바꿉니다. 틀린 경우 학습에서는 재선택, 게임에서는 오답 처리를 합니다.
3. `app.js`가 상태에 맞는 선택 버튼과 설명을 그리고 `setInterval`로 남은 시간을 표시합니다. 실제 판정에는 `performance.now()`와 종료 시각을 비교하므로 화면 갱신이 늦어져도 게임 시간이 늘어나지 않습니다.
4. `styles.css`의 색상 변수와 `@media`를 바꾸면 디자인과 작은 화면 배치를 수정할 수 있습니다.

예를 들어 생산자 항목을 고치려면 `data.js`의 `producers`에서 다음 형식을 사용합니다.

```js
['토끼풀', '☘️', '잎에서 광합성을 하여 스스로 양분을 만듭니다.']
```

문제 수를 변경할 때는 홈페이지·완료 화면·필터·README의 고정된 개수 표시와 데이터 개수 테스트도 함께 수정해야 합니다.

## 7. 개발자용 검증

Node.js가 설치된 환경에서 별도 패키지를 설치하지 않고 실행합니다. Node는 웹사이트를 사용하는 학생에게는 필요하지 않습니다.

```sh
npm test
```

테스트는 70개 포함 여부, 학습 재선택, 이전 문제 상태 유지, 최종 정답 점수, 중복 입력, 게임 오답, 정확히 120초의 만료, 전체 세트 이후 계속 출제를 확인합니다.
